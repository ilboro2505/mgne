# МОНЭ · лаборатория импульсных сетей

Симулятор модифицированной сети обобщённых нейронных элементов: вычислительное ядро на **Rust**, интерфейс на **TypeScript**, исполнение в браузере через **WebAssembly**. То же ядро работает в native CLI. Python и сервер для расчётов не требуются.

Приложение позволяет редактировать нейроны и связи, задавать общие параметры, выполнять расчёт по событиям и наблюдать динамику. JSON-конфигурации сохраняют исходные условия, снимки позволяют продолжить расчёт. Начальный ток до первого спайка выделен в отдельный вариант модели.

Это исследовательский симулятор. Обучение на данных и практическое преимущество архитектуры ещё предстоит проверить; перенос на другой стек сам по себе не является научной новизной.

## Запуск

Требуются [Rust через rustup](https://rustup.rs/) и Node.js **22.12 или новее**. Команды выполняются из каталога с этим README:

```sh
npm install
npm run dev
```

Откройте **http://127.0.0.1:5173**. Первый запуск устанавливает WASM target и соответствующий `Cargo.lock` инструмент `wasm-bindgen-cli` в `.tools/wasm-bindgen`, затем собирает ядро. Для первой сборки нужен доступ к реестрам зависимостей; установка Rust-компонентов может занять несколько минут. Отдельно подготовить инструменты можно командой `npm run setup`.

Если Rust установлен локально для этого проекта в `.tools/cargo` и `.tools/rustup`, npm-скрипты используют его автоматически. При обычной установке используются `cargo` и `rustup` из PATH.

## Работа с сетью

1. Выберите готовую конфигурацию или измените параметры, нейроны и связи.
2. Нажмите «Применить и сбросить». Редактирование конфигурации создаёт новый опыт; оно не меняет уже идущую динамику незаметно.
3. Выполните один шаг, пакет или включите непрерывный запуск. **Шаг — группа событий ближайшего модельного времени**, включая выходы из рефрактерности.
4. Сохраните конфигурацию для повторного запуска либо снимок для продолжения с теми же потенциалами и памятью входов.

Потенциалы на графике — выборки состояния после команд. Времена спайков берутся из событий ядра. Модельное время не зависит от скорости анимации.

Очень близкие причинно последовательные события могут иметь одинаковую округлённую отметку времени. В JSON-журнале сохраняются порядок групп и положительный `delta`; снимок дополнительно сохраняет поправку `timeCorrection`. Равенство видимых отметок само по себе не доказывает синхронность.

«Разность времён» показывает ряд Δt по номерам спайков с независимым выбором i/i+1 для обоих нейронов. Номера отсчитываются от указанного начала наблюдения и сохраняются при обрезке истории; Δt не является автоматически нормированной фазой.

Интерфейс рассчитан на 1–128 нейронов и хранит последние 1000 групп событий. CSV выгружает это окно; для полного журнала длинного опыта используйте CLI. Снимок продолжает расчёт, но не восстанавливает историю графиков и расположение узлов.

## Запуск без браузера

```sh
cargo run -p mgne-cli -- run --config examples/ring.json --events 1000 --output results.json --snapshot-out snapshot.json
cargo run -p mgne-cli -- resume --snapshot snapshot.json --events 1000 --output resumed.json
```

`--events` ограничивает число групп событий, а не спайков; диапазон — от 0 до 100 000, дополнительно `events × число нейронов <= 2 000 000` на вызов. Угасшая сеть остановится раньше. Без `--output` результат выводится в stdout. Для установленного внутри проекта Rust используйте `npm run cargo --` вместо `cargo`, например:

```sh
npm run cargo -- run -p mgne-cli -- run --config examples/oscillator.json --events 10
```

Примеры в [examples](examples): изолированный автогенератор, восприимчивое кольцо A, рефрактерное кольцо B, кольцо детекторов с начальным током и детектор без входа.

## Проверки и сборка

```sh
npm test
npm run build
npm run preview
```

`npm test` проверяет Rust-ядро, TypeScript, сопоставление индексов графиков и согласованность native/WASM на общих сценариях. Для отдельных проверок ядра: `cargo test --workspace` или `npm run cargo -- test --workspace`.

Production-сборка находится в `dist`, предварительный просмотр — **http://127.0.0.1:4173**. Статические файлы нужно обслуживать по HTTP; открытие `index.html` через `file://` не является поддерживаемым способом запуска Worker/WASM.

Браузерные сценарии:

```sh
npx playwright install chromium
npm run build
npm run test:browser
```

Вместо установки Chromium можно использовать уже установленный Chrome, задав `PLAYWRIGHT_CHANNEL=chrome` для запуска тестов. Браузерные сценарии проверяют управление, редактор, сохранение и восстановление состояния, графики и экспорт событий.

## Устройство проекта

| Каталог | Назначение |
|---|---|
| `crates/mgne-core` | Событийная динамика, валидация, снимки и WASM-обвязка |
| `crates/mgne-cli` | Запуск и продолжение симуляции из JSON |
| `web` | Интерфейс TypeScript, визуализация и Web Worker |
| `examples` | Воспроизводимые исходные конфигурации |
| `tests` | Проверки native/WASM и браузера |
| `scripts` | Подготовка инструментов и сборка Rust/WASM |
